# SURVEY DEMO — АДМИНИСТРАТИВНАЯ ПАНЕЛЬ
## Задача
Создать защищенную административную страницу для уже работающей анкеты. Существующую публичную анкету и ее подключение к Supabase не изменять.
## Адрес
Создать административную страницу по адресу /admin. Админка должна быть частью этого же сайта. На публичной странице анкеты не добавлять ссылку или кнопку для перехода в админку.
## Вход
При открытии /admin пользователь сначала должен видеть форму входа.
Поля:
- Email
- Пароль
Кнопка:
- «Войти»
Для входа использовать Supabase Auth существующего проекта. Не создавать и не прописывать в коде логин или пароль администратора. Не использовать secret key, service_role или пароль базы данных. Использовать уже имеющиеся в проекте API URL и Publishable key.
Если пользователь не авторизован, содержимое административной панели не должно отображаться.
## Сессия
После успешного входа пользователь должен видеть административную панель. После обновления страницы активная сессия должна корректно определяться, чтобы авторизованному пользователю не приходилось заново входить без необходимости.
## Административная панель
После успешного входа показать страницу с заголовком «Результаты исследования».
Предусмотреть следующие разделы:
- Обзор
- Аналитика
- Открытые ответы
- Респонденты
Предусмотреть кнопку «Выгрузить ответы в Excel».
Предусмотреть кнопку «Выйти».
## Выход
Кнопка «Выйти» должна завершать сессию Supabase Auth и возвращать пользователя к форме входа.
## Содержимое разделов
На этом этапе НЕ реализовывать аналитику, графики, выгрузку Excel и загрузку ответов респондентов из базы. Создать только интерфейс и навигацию административной панели. Для разделов использовать понятные пустые состояния, например: «Данные будут отображаться после подключения следующего этапа».
Не создавать фиктивные ответы, тестовых респондентов, случайные цифры, проценты или демонстрационные графики.
## Дизайн
Административная панель должна использовать тот же спокойный визуальный стиль, что и анкета.
Фон: #f2eff5
Карточки: #ffffff
Акцент: #705e82
Границы: #ddd7e3
Основной текст темный.
Интерфейс должен быть современным, спокойным, минималистичным и удобным.
Не создавать большие пустые пространства. Не использовать чрезмерные margin, padding, min-height и фиксированные высоты.
Не изменять дизайн публичной анкеты.
## Адаптивность
Админка должна корректно отображаться на компьютере, планшете и смартфоне. Не допускать горизонтальной прокрутки.
## Совместимость
Структура /admin должна в дальнейшем подходить для размещения на GitHub Pages.
## Важно
Не изменять существующую анкету.
Не изменять вопросы и ответы анкеты.
Не изменять существующую отправку данных в Supabase.
Не создавать новую таблицу Supabase.
Не изменять таблицу survey_responses.
Не создавать тестовые данные.
Не создавать логин или пароль администратора.
Не использовать secret key, service_role или пароль базы данных.
Не реализовывать на этом этапе получение survey_responses из базы.
Не реализовывать аналитику и графики.
Не реализовывать Excel.
Не изменять SKILL.md и SKILL2.md.
## Результат
Создать рабочую страницу /admin с формой входа через Supabase Auth, защищенным отображением интерфейса административной панели, навигацией по разделам и рабочим выходом из учетной записи. После выполнения проверить код на ошибки и остановиться.
