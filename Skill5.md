# SURVEY DEMO — ВЫГРУЗКА ОТВЕТОВ В EXCEL
## Задача
Сделать рабочей существующую кнопку «Выгрузить ответы в Excel» в административной панели. Выгружать реальные данные из public.survey_responses в файл формата .xlsx. Существующую анкету, административную панель, аналитику, открытые ответы, авторизацию и подключение к Supabase не изменять.
## Доступ
Выгрузка должна быть доступна только авторизованному пользователю административной панели.
Использовать уже загруженные реальные данные survey_responses или безопасно получать их через существующее подключение Supabase.
Не использовать secret key, service_role или пароль базы данных.
Не изменять RLS.
## Кнопка
Сделать существующую кнопку «Выгрузить ответы в Excel» активной.
Не создавать вторую кнопку.
При отсутствии ответов не создавать пустой файл и показать понятное сообщение.
## Формат файла
Создавать настоящий файл .xlsx, который корректно открывается в Microsoft Excel.
Имя файла: survey_responses.xlsx.
Один респондент = одна строка.
Один показатель или вопрос = один столбец.
## Столбцы Excel
Создать столбцы в следующем порядке:
1. № респондента
2. Дата отправки
3. Пол
4. Возраст
5. Частота стресса
6. Источники стресса
7. В каких ситуациях вам особенно трудно справляться со стрессом?
8. Что помогает вам восстанавливаться после стрессовой ситуации?
## Данные
№ респондента должен соответствовать нумерации в разделе «Респонденты».
Дата отправки берется из created_at и должна отображаться в понятном формате даты и времени.
Пол берется из gender.
Возраст берется из age_group.
Частота стресса берется из stress_frequency.
Источники стресса берутся из stress_sources.
Если в stress_sources выбрано несколько вариантов, записывать их в одну ячейку в читаемом виде через точку с запятой.
Если присутствует собственный вариант «Другое», сохранить его в Excel.
Открытые ответы difficult_situations и recovery_methods выгружать полностью, без сокращения, перефразирования и анализа.
Не выгружать технический id как отдельный столбец.
## Оформление Excel
Первая строка должна содержать русские заголовки столбцов.
Сделать заголовки читаемыми.
Установить разумную ширину столбцов.
Для двух столбцов с открытыми ответами включить перенос текста, чтобы длинные ответы было удобно читать.
Не добавлять фиктивные данные, графики, выводы или автоматически сформированные интерпретации.
## Техническая реализация
Реализовать создание .xlsx на стороне браузера способом, совместимым со статическим размещением проекта на GitHub Pages.
Допускается использование надежной клиентской библиотеки для создания .xlsx, например SheetJS.
Не создавать backend или сервер только ради Excel.
Не нарушать существующую работу Supabase и GitHub Pages.
## Ошибки
Если при создании файла возникает ошибка, показать пользователю понятное сообщение и не нарушать работу административной панели.
Не выводить секретные данные или технические ключи в файл.
## Не изменять
Не изменять публичную анкету.
Не изменять вопросы анкеты.
Не изменять таблицу survey_responses.
Не создавать новые таблицы.
Не изменять Supabase Auth.
Не изменять RLS.
Не изменять существующую аналитику, фильтры, раздел «Открытые ответы» и раздел «Респонденты».
Не изменять SKILL.md, SKILL2.md, SKILL3.md, SKILL4.md и SKILL5.md.
## Результат
После выполнения авторизованный пользователь нажимает «Выгрузить ответы в Excel» и получает файл survey_responses.xlsx со всеми реальными ответами. Проверить создание файла на текущих данных и убедиться, что открытые ответы выгружаются полностью. После проверки остановиться и не выполнять другие изменения проекта.
